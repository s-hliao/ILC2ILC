# ILC2Real Go1 jump videos

Side views of the recorded sim-to-sim jumps (`../../../trajectories/`), as MP4 (H.264, real time, 17 fps). Each
video can be paused and scrubbed in any player. They are regenerated by `scripts/make_animations.py`.

| folder | contents |
|---|---|
| `00_compare_all_methods/<robot>.mp4` | every method side by side, one test goal after another |
| `01_ours/` | ours: zero-shot on the test goals, the hardware stage (24 jumps), and the test goals after it |
| `02_ours_plus_dr_finetune/` | our learner + DR (A: DR fine-tune): zero-shot, hardware stage, after 24 jumps |
| `03_ours_plus_dr_scratch/` | our learner + DR (B: DR from scratch): hardware stage, after 24 jumps |
| `04_ours_trained_under_perturbation/<cond>/` | our hardware stage run under one constant perturbation, then the test goals on the nominal robot |
| `05_ppo_dr/`, `06_rma/` | zero-shot baselines on the test goals |
| `07_rma_crosstrial/` | RMA's 6 calibration jumps, then the test goals |
| `08_fada/` | FADA's on-robot adaptation, then the test goals |
| `09_jumpilc_per_goal/` | per-goal ILC: its trials are flown directly on the test goals, trial by trial |

Files in each folder:
- `hardware_stage_<robot>.mp4`: the real jumps batch by batch, one panel per training goal. Earlier batches stay as
  faded paths.
- `<when>_test_goals_<robot>.mp4`: the 8 reserved test goals, which are never trained on and never flown in the
  hardware stage, all jumping at once. `<when>` is `zeroshot`, `after_24jumps`, `after_calibration` or
  `after_adaptation`.

Robots: r1, s1, r4, r5; the `04_` runs use r4m in place of r4. Each video is one episode per goal at the evaluation
seed (701). The success rates in the figures come from the full evaluations in `log/dilc/plane/`.

## The same jumps in MuJoCo

`scripts/replay_mujoco.py` poses the Go1 (mujoco_menagerie) from the recorded ground truth, with the jump's box.
Run it from `src/ilc_mjx` on a machine with a display. It needs `pip install mujoco numpy` and a `mujoco_menagerie`
checkout (`$MUJOCO_MENAGERIE_PATH` or `~/mujoco_menagerie`).

```bash
# one method, one robot, all 8 test goals in turn (each loops until you press N)
python scripts/replay_mujoco.py trajectories/eval_ours_24jumps.npz --robot real_r1 --speed 0.5
# one goal (x, box height in m)
python scripts/replay_mujoco.py trajectories/eval_dr_scratch_24jumps.npz --robot real_s1 --goal 0.54 0.14
# the hardware stage on one training goal, its batches in turn
python scripts/replay_mujoco.py trajectories/gate_loose.npz --robot real_s1 --goal 0.575 0.15
```

Viewer keys:
- space: pause / resume
- `,` / `.`: step 10 ms back / forward
- R: restart
- N: next jump
- Q: quit

The mouse orbits, pans and zooms as in MuJoCo's simulate.

On a headless machine, render MuJoCo's own view to an MP4 instead:

```bash
MUJOCO_GL=egl python scripts/replay_mujoco.py trajectories/eval_ours_24jumps.npz --robot real_r1 --record r1_test_goals.mp4 --size 960 540
```
